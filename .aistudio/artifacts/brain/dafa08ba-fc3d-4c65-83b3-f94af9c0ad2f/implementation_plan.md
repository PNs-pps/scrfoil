# แผนการปรับปรุงเมนูม้วนฟอยล์ (ฟอยล์เก่า/มีปัญหา & ทำความสะอาด UI)

## งานที่ดำเนินการเรียบร้อยแล้ว:
1. **ลบช่องติ๊กข้างช่องค้นหาออก**:
   - นำช่องติ๊กเลือก `quick-checkbox-reverse-only` ที่อยู่ด้านข้างช่องค้นหาในหน้าเมนูม้วนฟอยล์ออกตามความต้องการ เพื่อคืนพื้นที่ให้ช่องค้นหาและปุ่มค้นหาขั้นสูงดูสะอาดตา

2. **เปลี่ยนชื่อแท็บสถานะ**:
   - เปลี่ยนชื่อแท็บสถานะจาก `ใช้อีกด้าน` เป็น **`เก่า/มีปัญหา ({reverseOnlyCount})`**
   - ช่วยให้ผู้ใช้สามารถคลิกกรองเฉพาะม้วนฟอยล์เก่าหรือมีปัญหาได้อย่างรวดเร็ว

3. **นำอิโมจิออกทั้งหมด (เอาอิโมจิออก)**:
   - นำอิโมจิ `🔄` และ `⚠️` ออกจากทุกจุดที่เกี่ยวข้องกับฟังก์ชันนี้ (แท็บสถานะ, แถบการกรอง, ป้ายกำกับบนการ์ดมือถือ, แถวตาราง Desktop, เมนูการจัดการม้วน, ป็อปอัพตัดสต๊อก `CutStockModal`, `AddFoilModal`, `EditFoilModal`, `RollDetailModal`, และ `RollUsageHistoryModal`)
   - ใช้สไตล์ตัวอักษรคมชัดและการจัดวางที่เป็นระเบียบแทน
