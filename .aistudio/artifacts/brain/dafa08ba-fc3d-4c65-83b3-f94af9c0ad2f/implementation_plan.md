# แผนพัฒนา: ระบบจองม้วนฟอยล์และคิวผลิต SO (Foil Roll Reservation & Production Queue)

แผนงานนี้จัดทำขึ้นเพื่อ**ยกเลิกการตรวจ SO เดิมทั้งหมด** และเปลี่ยนเป็น **"ระบบจองม้วนฟอยล์และคิวผลิต SO"** พร้อมเพิ่ม **"ปุ่มแก้ไขสำหรับเปลี่ยนฟอยล์"** และ **"ปุ่มยกเลิกการผลิต"** ตามความต้องการเพิ่มเติมของผู้ใช้

---

### User Review & Critical Decisions

> [!IMPORTANT]
> **สรุปสาระสำคัญตามผลการซักถามและข้อตกลงกับผู้ใช้ (Updated):**
> 1. **ยกเลิกการตรวจ SO ทั้งหมด:** เปลี่ยนแท็บเมนูด้านบนจาก "ศูนย์ตรวจ SO" เป็น **"ระบบจองม้วนและคิวผลิต SO"** และถอด UI ตรวจสอบ Audit/Bug ออก เพื่อให้หน้าจอสะอาด คล่องตัว ไม่สับสน
> 2. **รูปแบบการกรอกข้อมูล SO ใหม่:**
>    - มีตัวเลือกชัดเจนให้เลือกระหว่าง: **"ตัดทันที (ผลิตจริง)"** หรือ **"จองรอตัด (คิวผลิต)"**
>    - ช่องกรอกข้อมูล: **รหัส SO**, **จำนวนเมตรที่ต้องการตัด**, และ **"NG หัวท้าย (ยอดรวม)"** (กรอกช่องเดียวเป็นยอดรวม)
> 3. **การแสดงสถานะม้วนฟอยล์ 3 มิติ:**
>    - แสดงตัวเลขชัดเจน 3 ค่า: **มีการจองกี่เมตร**, **เหลือจริงกี่เมตร**, และ **ผลิตจริงแล้วจะเหลือกี่เมตร**
>    - **ไทม์ไลน์หลอดสถานะ 3 สี (Progress Timeline Tube):**
>      - 🟢 **สีเขียว:** เหลือจริงที่ยังว่าง (Available Meters)
>      - 🟡 **สีเหลือง:** ยอดที่ถูกจองรอตัด (Reserved Meters)
>      - ⚪ **สีเทา:** ยอดที่ตัดผลิตใช้ไปแล้ว + NG (Used & Depleted Meters)
> 4. **หน้าประวัติ SO (History & Queue) และปุ่มควบคุมการผลิตใหม่:**
>    - 🟢 **ตัดจริงเป็นสีเขียว** (Status Badge: ผลิตจริงแล้ว)
>    - 🟡 **รอตัดเป็นสีเหลือง** (Status Badge: จองรอตัด)
>    - ⚡ **ปุ่มกดยืนยันว่าผลิตจริงแล้ว:** ย้ายจากยอดจองไปเป็นตัดจริง หักสต๊อกม้วน และเปลี่ยนเป็นสีเขียว
>    - 🔄 **ปุ่มแก้ไขสำหรับเปลี่ยนฟอยล์ (Change / Reallocate Roll):** ย้ายคิวการผลิต/การตัดไปม้วนฟอยล์อื่น โดยระบบจะคืนยอดจองให้ม้วนเดิม และไปกันยอดจองที่ม้วนใหม่ให้อัตโนมัติ พร้อมตรวจเช็กว่าม้วนใหม่มีเมตรเพียงพอหรือไม่
>    - 🚫 **ปุ่มยกเลิกการผลิต (Cancel Production):** ยกเลิกคิวจอง SO และคืนยอดเมตรกลับสู่ม้วนฟอยล์ทันที หลอดสถานะสีเขียวจะกลับมาเต็มตามเดิม

### 1. Proposed Changes & Technical Architecture

#### Phase 1: Data Structures & State Management (`src/types.ts`, `src/lib/firebase.ts`)
- ปรับแต่ง `StockCutRecord`:
  - `status?: 'reserved' | 'completed' | 'cancelled'`
    - `'completed'`: ตัดจริง / ผลิตเสร็จสิ้นแล้ว (แสดงสีเขียว)
    - `'reserved'`: จองรอตัด / คิวรอผลิต (แสดงสีเหลือง)
    - `'cancelled'`: ยกเลิกการผลิตแล้ว (คืนยอดสต๊อก)
  - `ngHeadTailMeters?: number` (เชื่อมโยงกับ `ngMeters` เพื่อเก็บบันทึกยอดรวม NG หัวท้าย)
  - `confirmedAt?: string`, `confirmedBy?: string` (บันทึกเมื่อกดยืนยันผลิตจริง)
  - `cancelledAt?: string`, `cancelledBy?: string`, `cancelReason?: string` (บันทึกเมื่อกดยกเลิกการผลิต)
  - `reallocatedFromRollId?: string` (ประวัติหากมีการสลับเปลี่ยนม้วนฟอยล์)
- ปรับแต่งการคำนวณของ `FoilRoll`:
  - `reservedMeters`: ยอดรวมเมตรที่ถูกจอง (เฉพาะรายการที่เป็น `'reserved'`)
  - `projectedRemainingMeters`: ยอดคาดการณ์หลังตัดจริง = `remainingMeters - reservedMeters`
  - ฟังก์ชันคำนวณ Realtime Helpers `calculateRollReservationMetrics(roll, records)`

#### Phase 2: ปรับฟอร์มบันทึกการตัด/จอง (`src/components/CutStockModal.tsx`)
- เพิ่ม Segmented Mode Switcher ชัดเจน:
  - ✂️ **ตัดทันที (ผลิตจริงแล้ว)** $\rightarrow$ หักสต๊อกม้วนทันที สถานะเป็น 'completed' (สีเขียว)
  - 📋 **จองรอตัด (คิวผลิต)** $\rightarrow$ กันสต๊อกไว้เป็นยอดจอง สถานะเป็น 'reserved' (สีเหลือง) ยังไม่ตัดยอดจริงออกจากม้วน
- ช่องกรอกข้อมูลครบถ้วน:
  - รหัส SO
  - จำนวนเมตรที่ต้องการตัด
  - **NG หัวท้าย (ยอดรวม)** ปรับ Label เป็น "ยอดรวม NG หัวท้าย (เมตร)"
- แถบแสดงพรีวิวหลอดสถานะ 3 สีของม้วนที่เลือกแบบ Real-time: แสดงให้เห็นยอดก่อนและหลังจอง/ตัดทันที

#### Phase 3: ไทม์ไลน์หลอดสถานะ 3 สี (`FoilStatusTube.tsx`)
- สร้าง Reusable Component `FoilStatusTube`:
  - สัดส่วนเปอร์เซ็นต์อิงจากความยาวลูกเต็ม (`totalMeters`):
    - ⚪ **สีเทา** (`bg-slate-300` / `bg-slate-400`): ยอดใช้ไปแล้ว (`usedMeters + ngMeters`)
    - 🟡 **สีเหลือง** (`bg-amber-400`): ยอดจองรอตัด (`reservedMeters`)
    - 🟢 **สีเขียว** (`bg-emerald-500`): ยอดเหลือจริงพร้อมใช้ (`remainingMeters - reservedMeters`)
  - แถบสรุป 3 มิติ:
    - 📦 **เหลือจริง:** `remainingMeters` ม.
    - ⏳ **จองคิว:** `reservedMeters` ม.
    - 🎯 **ผลิตจริงแล้วจะเหลือ:** `projectedRemainingMeters` ม.
- นำไปติดตั้งใน:
  - การ์ดม้วนฟอยล์ในหน้า "ม้วนฟอยล์" (`FoilRollTable`)
  - หน้าต่างดูรายละเอียดม้วน (`RollDetailModal`)
  - หน้าต่างฟอร์มตัด/จอง (`CutStockModal`)
  - หน้าต่างรายละเอียด SO (`SODetailModal`)

#### Phase 4: หน้าระบบจองม้วนและคิวผลิต SO (`src/components/SOReservationHubView.tsx`)
- เมนูหลักบน Navbar และ Mobile Bottom Nav เปลี่ยนชื่อเป็น **"ระบบจองม้วนและคิวผลิต SO"**
- หน้าจอนี้จะรวมศูนย์การทำงานของคิวผลิต:
  - **แถบ 1: คิว SO รอตัด (Active Queue):**
    - แสดงรายการ SO ที่รอตัดทั้งหมด
    - มีปุ่มทางลัดด่วนในแถว:
      - ⚡ **ยืนยันผลิตจริง** (เปิด Modal ยืนยัน และตัดยอดจริงทันที)
      - 🔄 **เปลี่ยนฟอยล์** (เปิด Modal เลือกม้วนฟอยล์อื่นที่สเปกตรงกัน)
      - 🚫 **ยกเลิกการผลิต** (คืนยอดจองกลับม้วนทันที)
  - **แถบ 2: ม้วนฟอยล์และการจัดสรรคิว (Roll Allocation):**
    - รายการม้วนฟอยล์ทั้งหมดพร้อมหลอดสถานะ 3 สี เรียงตามยอดคิวที่รอตัด
  - **แถบ 3: ประวัติที่ผลิตจริงแล้ว (Completed Production):**
    - รายการที่ยืนยันการตัดจริงแล้ว พร้อมวันที่เวลาที่ผลิตเสร็จ

#### Phase 5: ปรับหน้าประวัติตัดและหน้าต่างรายละเอียด SO (`src/components/CuttingHistoryTable.tsx`, `SODetailModal.tsx`)
- ในตารางประวัติ (`CuttingHistoryTable`):
  - Badge สถานะชัดเจน:
    - 🟢 **ตัดจริง** (`bg-emerald-100 text-emerald-900 border-emerald-300`)
    - 🟡 **รอตัด** (`bg-amber-100 text-amber-950 border-amber-300`)
    - ⚪ **ยกเลิก** (`bg-slate-100 text-slate-500 border-slate-200`)
  - ในคอลัมน์ "จัดการ" และในหน้าต่าง `SODetailModal`:
    - ปุ่ม **"⚡ ยืนยันผลิตจริง"** (สำหรับรายการรอตัด)
    - ปุ่ม **"🔄 เปลี่ยนฟอยล์"** (เปิด Modal ให้เลือกม้วนฟอยล์ใหม่ที่มีหน้ากว้าง/ลายเดียวกัน และมีเมตรพอ)
    - ปุ่ม **"🚫 ยกเลิกการผลิต"** (มี Dialog สอบถามเหตุผลและยืนยันคืนสต๊อก)
- สร้าง Modal พิเศษ:
  - `ReallocateRollModal.tsx`: แสดงม้วนเดิม vs ตัวเลือกม้วนใหม่ พร้อมหลอดสถานะเปรียบเทียบ ให้สลับม้วนได้ง่ายและปลอดภัย
  - `CancelProductionModal.tsx`: ป๊อปอัปยืนยันการยกเลิกพร้อมคำนวณเมตรที่จะได้รับคืน

### 2. Verification & Testing Plan

1. **ทดสอบสร้าง SO แบบจองรอตัด:**
   - กรอก SO, จำนวน 400 ม., NG หัวท้าย 20 ม. $\rightarrow$ บันทึกเป็น "จองรอตัด"
   - ยอดจองเพิ่ม 420 ม. หลอดสถานะของม้วนเพิ่มแถบสีเหลือง ยอดผลิตจริงแล้วจะเหลือลดลงตามจริง
2. **ทดสอบปุ่ม "เปลี่ยนฟอยล์" (Reallocate Roll):**
   - กดปุ่ม "เปลี่ยนฟอยล์" บนรายการที่รอตัด $\rightarrow$ เลือกม้วนฟอยล์เป้าหมายใหม่
   - ตรวจสอบว่าม้วนเดิมได้รับยอดจองคืน (หลอดสีเหลืองลดลง ยอดสีเขียวกลับมา) และม้วนใหม่มียอดจองเพิ่มขึ้นอย่างถูกต้อง
3. **ทดสอบปุ่ม "ยกเลิกการผลิต" (Cancel Production):**
   - กดปุ่ม "ยกเลิกการผลิต" บนรายการที่รอตัด $\rightarrow$ กดยืนยัน
   - ตรวจสอบว่าคิวถูกยกเลิก ม้วนฟอยล์ได้รับการคืนยอดจอง 100% หลอดสถานะสีเขียวกลับมาเท่าเดิม
4. **ทดสอบปุ่ม "ยืนยันว่าผลิตจริงแล้ว" (Confirm Production):**
   - กดปุ่ม "ยืนยันว่าผลิตจริงแล้ว" $\rightarrow$ สถานะเปลี่ยนเป็นสีเขียว "ตัดจริง" ยอดจองถูกโอนไปเป็นยอดตัดใช้จริงในม้วนฟอยล์
5. **ทดสอบการสร้าง SO แบบ "ตัดทันที":**
   - บันทึกแบบ "ตัดทันที" $\rightarrow$ หักสต๊อกม้วนฟอยล์ทันที และขึ้นสถานะสีเขียว "ตัดจริง"
