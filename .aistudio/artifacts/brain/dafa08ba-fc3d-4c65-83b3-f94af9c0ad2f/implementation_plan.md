# แผนการปรับปรุงระบบจัดการสต๊อกฟอยล์และ PU Foam (สอดคล้องกับอุปกรณ์ใหม่และประสบการณ์ใช้งาน)

## สรุปความต้องการที่ได้รับและผลการตัดสินใจ
1. **ซ่อนไอคอนตรวจสอบบัค (🐞) สำหรับผู้เข้าชม**: แสดงเฉพาะแอดมิน/ผู้ควบคุมงานที่ล็อกอินแล้ว เพื่อป้องกันความเข้าใจผิดของผู้เข้าชมทั่วไป
2. **ปรับปรุงความปลอดภัยการซิงค์คลาวด์บนอุปกรณ์ใหม่**: เมื่อเปิดใช้งานบนเครื่องใหม่ ข้อมูลคลาวด์จะเป็น Source of Truth หลัก และป้องกันการ Auto-upload ข้อมูลเริ่มต้น/ว่างเปล่าทับคลาวด์เมื่อยังไม่ได้รับสิทธิ์ปลดล็อก
3. **จัดเรียงระบบ Audit Log**: เรียงจากใหม่ล่าสุดไปเก่าสุด (Newest at top) ให้สอดคล้องกับตารางประวัติการตัดฟอยล์
4. **แก้ไขการแสดงผลทับซ้อนของแผง "ค้นหาขั้นสูง"**: ปรับโครงสร้าง Popup/Drawer ให้มี Backdrop ชัดเจน หรือ Accordion แบบเลื่อนลงอย่างสวยงาม ไม่ทับซ้อนปุ่มและรายการม้วน
5. **ปรับปุ่มย้อนกลับในหน้าตั้งค่า**: จัดระเบียบปุ่ม Navigation ให้เรียบร้อย ไม่แสดงปุ่มย้อนกลับซ้ำซ้อนหรือแปลกตา
6. **เพิ่มตัวเลือกกรอกช่อง SO ใน Touch Numpad**: เพิ่ม target และปุ่มสลับกรอกช่องรหัส SO ในแผง Touch Numpad
7. **เพิ่มการ์ดส่งออกรายงาน Excel บนหน้าแดชบอร์ด**: เพิ่ม Banner / Action Card ชัดเจนพร้อมคำอธิบายการส่งออก Excel รายเดือน/ประจำปี
8. **เพิ่มตัวกรองสถานะไฮไลต์เหลือง/แดง ในการค้นหาขั้นสูง**: สามารถคลิกเลือกกรองเฉพาะม้วนฟอยล์ที่ติดไฮไลต์ "เหลือง (≤ 200 ม.)" หรือ "แดง (≤ 50 ม.)" ได้ทันที

## แผนการทดสอบและตรวจสอบคุณภาพ (Verification Plan)
1. **ทดสอบมุมมองผู้เข้าชม (Visitor Mode)**: ตรวจสอบว่าไอคอน 🐞 และกล่องเตือนบัคถูกซ่อนหมดจด ไม่มีข้อความเตือนให้ผู้เข้าชมตกใจ
2. **ทดสอบแผงค้นหาขั้นสูง**: เปิดปิดบนหน้าจอขนาดมือถือ/แท็บเล็ต ตรวจสอบว่าไม่ทับซ้อนปุ่มอื่น และทดสอบกรองม้วนไฮไลต์เหลือง/แดง
3. **ทดสอบการจัดเรียง Audit Log**: บันทึกการตัดแล้วดูประวัติ ตรวจสอบว่ารายการใหม่อยู่บนสุดเสมอ
4. **ทดสอบ Touch Numpad**: ทดสอบกดเลือกช่อง SO และพิมพ์ตัวเลขรหัส SO ได้ราบรื่น
5. **ทดสอบปุ่มส่งออก Excel บนแดชบอร์ด**: ตรวจสอบการดาวน์โหลดไฟล์ .xlsx ครบถ้วน
6. **ทดสอบ Build & Test Suite**: รัน `lint_applet`, `compile_applet`, และ `vitest` ผ่าน 100%
