# แผนการพัฒนา: ระบบแบ่งหน้าประวัติ SO (50 รายการ/หน้า) + รายงาน Excel ด้านบนสุด + แดชบอร์ดแซนวิชแยกสีหลัก/สีย่อย/ความหนา

## 1. การแบ่งหน้าประวัติการตัด SO (50 รายการต่อหน้าเพื่อประหยัด Read)
- **ตำแหน่งไฟล์:** `src/components/CuttingHistoryTable.tsx` และ `src/App.tsx`
- **การทำงาน:**
  - เพิ่มระบบ Pagination แสดงผลทีละ 50 รายการต่อหน้า (Page 1, 2, 3...)
  - มีแถบควบคุมด้านล่างและด้านบน: ปุ่ม "ก่อนหน้า (Prev)", ปุ่ม "ถัดไป (Next)", เลขหน้าปัจจุบัน และตัวเลือกลัดไปยังหน้าต่างๆ
  - แสดงป้ายระบุช่วงที่กำลังแสดงผล เช่น "แสดงรายการที่ 1 - 50 จากทั้งหมด 248 รายการ"
  - การค้นหา กรองประเภทฟอยล์ และจัดเรียง (Sort) ยังคงประมวลผลครอบคลุมทุกรายการ แล้วแบ่งหน้าใหม่อัตโนมัติเมื่อผลลัพธ์เปลี่ยน
  - ปรับปรุงการดึงข้อมูลใน `subscribeToStockCutRecords` และระบบแคชในเครื่อง (IndexedDB) เพื่อลดปริมาณ Read โควต้า Firebase อย่างมีประสิทธิภาพ

## 2. ย้ายตำแหน่งรายงาน Excel ให้อยู่ด้านบนสุดเหนือแดชบอร์ดแซนวิช
- **ตำแหน่งไฟล์:** `src/components/PuSandwichView.tsx`
- **การทำงาน:**
  - ย้ายกล่องรายงาน Excel ให้ขึ้นมาอยู่ด้านบนสุด เหนือหัวข้อและแถบ KPI ทั้งหมด
  - ออกแบบเป็นการ์ดพรีเมียมที่โดดเด่น สังเกตเห็นได้ง่าย พร้อมปุ่มดาวน์โหลดรายงาน Excel ด่วน หรือเปิดหน้าต่างเลือกช่วงวันที่และฟิลเตอร์ละเอียด
  - แสดงสรุปจำนวนรายการและช่วงเวลาปัจจุบันที่พร้อมออกรายงานในคลิกเดียว

## 3. แดชบอร์ดแซนวิชจัดกลุ่มสีหลักภาษาไทย สีย่อย แหล่งเหล็ก และความหนา
- **ตำแหน่งไฟล์:** `src/components/PuSandwichView.tsx` และยูทิลิตี้การสกัดสี
- **การทำงาน:**
  - **การสกัดสีหลัก (Primary Thai Color):** ใช้ข้อมูลภาษาไทยจากชื่อสีคอยล์ เช่น "ขาว AW", "ขาว AW/Z.cool", "ขาว" จะถูกรวมกลุ่มเป็น **"สีขาว"** เหมือนกัน, "ดำ", "ดำด้าน" -> "สีดำ", "น้ำเงิน", "น้ำเงินสด" -> "สีน้ำเงิน", "เขียว", "เขียวบางจาก" -> "สีเขียว" ฯลฯ
  - **การแจกแจงสีย่อยและแหล่งเหล็ก (Sub-variants & Steel Origin):**
    - ภายใต้สีหลัก จะแยกย่อยตามชื่อเต็มของสีคอยล์และแหล่งเหล็ก เช่น:
      - "ขาว AW" (เหล็กนอก)
      - "ขาว AW/Z.cool" (เหล็ก Blue Scope)
  - **การแจกแจงตามความหนา (Thickness Breakdown):**
    - ในแต่ละสีย่อย แยกตามความหนา เช่น 0.35 มม., 0.40 มม., 0.45 มม.
    - แสดงสถิติ: เมตรความยาวงานรวม (ม.), น้ำหนักเหล็กที่ใช้ (กก. / ตัน), จำนวน SO, และยอด NG เสียหาย (กก. / ม.)
  - ออกแบบ UI สวยงาม ชัดเจน รองรับการพับ/กาง (Accordion) และมีแท็กสี (Color Tag) กำกับชัดเจน
