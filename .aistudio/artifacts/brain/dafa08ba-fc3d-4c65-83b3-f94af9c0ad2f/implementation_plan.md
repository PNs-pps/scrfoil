# แผนการพัฒนา: ขยาย Numpad สู่หน้าตัดฟอยล์ + ปรับ UI สรุปสีแดชบอร์ดแซนวิชให้กะทัดรัด + ปรับสีท้องขาวบนกราฟและประวัติ SO ให้คมชัด

แผนงานนี้ครอบคลุมการต่อยอดระบบ Numpad ให้รองรับการตัดฟอยล์, การปรับรูปแบบ UI สรุปสีคอล์ยในแดชบอร์ดแซนวิชให้สวยงาม กะทัดรัด และเข้ากับสีจริง, พร้อมทั้งปรับโทนสีของ "ท้องขาว" ให้คมชัด โดดเด่น ไม่กลืนกับพื้นหลังทั้งในกราฟและหน้าประวัติ SO

---

## สรุปการตัดสินใจจากการสัมภาษณ์ (User Review & Critical Decisions)

> [!IMPORTANT]
> สรุปผลการยืนยันรูปแบบจากผู้ใช้งาน:

- **1. แถบควบคุม 5 ส่วนบน Touch Numpad ในหน้าตัดฟอยล์:**  
  นำโครงสร้างแถบควบคุม 5 ส่วน (1. ลำดับ SO, 2. ช่องกรอก SO, 3. กรอกเมตร, 4. NG, 5. เพิ่ม SO) ไปใช้งานในหน้าต่างตัดสต๊อกฟอยล์ (`CutStockModal.tsx`) เช่นเดียวกับหน้าตัดแซนวิช เพื่อให้ผู้ใช้งานคุ้นเคยและทำงานได้รวดเร็วเหมือนกัน
- **2. การแสดงผลสีหลักและสีย่อยในแดชบอร์ดแซนวิช:**  
  เลือกใช้ **"การ์ดกะทัดรัดแบบพับกางได้ พร้อมแถบสีกำกับชัดเจน" (Compact Accordion Cards)** ปิดเนื้อหาตารางย่อยไว้เป็นค่าเริ่มต้น (Collapsed by default) แสดงเฉพาะแถบสรุปยอดเมตร/น้ำหนักที่กระชับ และปรับแต่งชุดสีพื้นหลัง/ขอบให้ตรงกับสีคอล์ยจริง (เช่น สีขาว, สีดำ, สีน้ำตาล, สีเขียว, สีฟ้า, สีเทา)
- **3. โทนสีของ "ท้องขาว" บนกราฟและประวัติ SO:**  
  เลือกใช้ **"ขาวมุกตัดขอบเทาเข้ม พร้อมตัวหนังสือสีเข้มอ่านง่าย" (Pearl White with Dark Slate Border)** ทั้งบนแท่งกราฟฟอยล์ (เส้นขอบ `#475569` ชัดเจน) และป้ายสถานะในหน้าประวัติ SO (`border-2 border-slate-700 bg-slate-100 text-slate-950`) เพื่อให้มองเห็นได้ชัดเจนในทุกมุมมอง ไม่กลืนไปกับพื้นหลังสีขาวหรือสีสว่าง

## 1. ภาพรวมและแนวคิดหลัก (Overview & Core Concept)

- **ผู้ใช้งานเป้าหมาย:** ช่างคุมเครื่องตัดฟอยล์, ช่างตัดแผ่น PU Sandwich, และหัวหน้าฝ่ายผลิตที่ตรวจสอบข้อมูลผ่านแดชบอร์ด
- **ประเด็นปัญหาเดิม:**
  1. ช่างตัดฟอยล์ยังไม่ได้ใช้ความสะดวกของ Numpad 5 ช่อง ทำให้ต้องสลับคลิกหลายจุด
  2. แดชบอร์ดสรุปสีคอล์ยของแซนวิชกางตารางย่อยออกมาทั้งหมด ทำให้หน้าจอมีความยาวมากเกินไปและสีการ์ดบางสียังไม่สะท้อนสีคอล์ยจริง
  3. ป้ายตัวเลือกและแท่งกราฟของ "ท้องขาว" กลืนไปกับพื้นหลังสีขาว ทำให้มองไม่เห็นหรือเข้าใจผิดว่าเป็นพื้นที่ว่าง
- **ผลลัพธ์ที่ได้:** ประสบการณ์ใช้งานบนแท็บเล็ตเป็นมาตรฐานเดียวกันทั้งระบบ, แดชบอร์ดอ่านง่ายสบายตาในหน้าเดียว, และมองเห็นสถิติท้องขาวได้อย่างชัดเจน

## 2. ประสบการณ์ผู้ใช้และการออกแบบส่วนต่อประสาน (User Experience & Visual Design)

### 2.1 แถบ Numpad 5 ช่องในหน้าตัดฟอยล์ (`CutStockModal.tsx`)
- เมื่อเปิดแป้น Numpad ในหน้าตัดฟอยล์ ด้านบนจะแสดงแถบควบคุม 5 ช่อง:
  1. `1. ลำดับ SO`: เลือกลำดับใบสั่งซื้อฟอยล์ (ใบที่ 1, ใบที่ 2...)
  2. `2. ช่องกรอก SO`: แตะเพื่อพิมพ์เลขที่ SO
  3. `3. กรอกเมตร`: แตะเพื่อป้อนเมตรฟอยล์ที่ตัดใช้
  4. `4. NG`: แตะเพื่อป้อนเมตรของเสียหัวท้าย
  5. `5. เพิ่ม SO`: แตะเพื่อเพิ่มรายการใบสั่งตัดฟอยล์ใบถัดไปทันที
- ปุ่ม "ช่องถัดไป" จะหมุนเวียนจาก SO -> เมตร -> NG -> ไปใบถัดไปหรือสร้างใบใหม่อัตโนมัติ

### 2.2 ปรับ UI สรุปสีแดชบอร์ดแซนวิชให้กะทัดรัด (`PuSandwichColorBreakdown.tsx` & `thaiColorCategorizer.ts`)
- ปรับเปลี่ยนจากการ์ดยาวแบบกางเต็ม เป็น **Compact Accordion Cards**:
  - เริ่มต้นแบบพับเก็บ (Collapsed) แสดงแถบสรุปหัวข้อสูงเพียง ~44px มีแถบสีจริงกำกับชัดเจนด้านซ้าย
  - แสดงตัวเลขสรุป: ชื่อสีหลัก, จำนวนสีย่อย, เมตรผลิตรวม, น้ำหนักรวม, และของเสีย NG
  - แตะเพื่อกางดูรายละเอียดสีย่อย (เช่น ขาว AW, ขาว AW/Z.cool) และตารางความหนาเฉพาะกลุ่มที่ต้องการดู
  - เพิ่มปุ่ม "กางทั้งหมด" และ "พับทั้งหมด" เพื่อความสะดวกในการตรวจสอบ
- ปรับแต่ง Color Palette ของกลุ่มสีหลักให้เข้ากับเฉดสีคอล์ยจริง:
  - สีขาว: แถบขาวมุกตัดขอบเทา `#e2e8f0` / จุดสี `#f8fafc` มีเส้นขอบชัดเจน
  - สีดำ: ดำเข้มออบซิเดียน `#0f172a`
  - สีน้ำตาล: น้ำตาลช็อกโกแลต `#78350f`
  - สีเขียว: เขียวใบไม้ `#15803d`
  - สีฟ้า/น้ำเงิน: น้ำเงินเข้มโคบอลต์ `#1d4ed8`
  - สีเทา: สเลทเทาเข้ม `#475569`

### 2.3 การปรับสี "ท้องขาว" บนแท่งกราฟฟอยล์และหน้าประวัติ SO
- **แท่งกราฟและ Legend (`MonthlyFoilUsageBarChart.tsx` / `soFormatter.ts`):**
  - แท่งกราฟของ "ขาว / ท้องขาว": ใช้สีขาวมุก `#f1f5f9` พร้อมเส้นขอบคมชัด `stroke="#475569" strokeWidth={1.5}`
  - จุดสีและ Legend: ใช้กรอบขาวมุกตัดขอบเทาเข้ม `#334155` เด่นชัดเจน
- **ป้ายในหน้าประวัติ SO (`CuttingHistoryTable.tsx` & โมดอลที่เกี่ยวข้อง):**
  - ปรับป้าย "ขาว" ของตัวเลือกท้องพิเศษให้เป็น `bg-slate-100 text-slate-950 border-2 border-slate-700 font-black shadow-xs` พร้อมจุดสีขาวมุกขอบดำหนา

## 3. สถาปัตยกรรมทางเทคนิคและการเชื่อมโยงข้อมูล (Technical Architecture)

```

│    (1. ลำดับ SO | 2. เลขที่ SO | 3. เมตรที่ใช้ | 4. NG | 5. เพิ่ม SO)  │
└─────────────────────────────────┬──────────────────────────────────────┘
                                  │
                                  ▼
┌────────────────────────────────────────────────────────────────────────┐
│ TouchNumpad (Shared Component)                                         │
│  - ใช้งานร่วมกันทั้ง PU Sandwich และ Foil Cutting                       │
│  - ควบคุมการป้อนค่าและสลับแถวได้อย่างราบรื่น                              │

┌────────────────────────────────────────────────────────────────────────┐
│ PuSandwichColorBreakdown (Compact UI)                                  │
│  - Default collapsed, compact summary headers                          │

┌────────────────────────────────────────────────────────────────────────┐

│  - MonthlyFoilUsageBarChart: Pearl white bar with dark slate stroke    │
│  - CuttingHistoryTable: Pearl white badge with border-slate-700        │

```

## 4. แผนงานการดำเนินการ (Implementation Steps)

1. **ปรับปรุง `CutStockModal.tsx`:**
   - สร้าง `soToolbarConfig` จาก `orders` และ `activeNumpadTargetId`
   - ส่ง `soToolbar={soToolbarConfig}` เข้าสู่ `<TouchNumpad>`
   - ปรับการทำงานของ `handleNextNumpadTarget` และการป้อนค่า SO number / meters / NG ให้หมุนเวียนราบรื่น
2. **ปรับปรุง `PuSandwichColorBreakdown.tsx` และ `thaiColorCategorizer.ts`:**
   - ปรับ `defaultExpanded = false` และออกแบบโครงสร้างการ์ดหัวข้อให้กะทัดรัด (ความสูงกระชับ มีแถบสีและไอคอนคมชัด)
   - ปรับสไตล์สีคอล์ยใน `KNOWN_BASE_THAI_COLORS` ให้ตรงกับสีจริงในโรงงาน
3. **ปรับปรุงสีของ "ท้องขาว" ในกราฟและตาราง:**
   - `MonthlyFoilUsageBarChart.tsx` และ `soFormatter.ts`: ใส่ `stroke` และสีขาวมุกให้แท่งกราฟลายขาว
   - `CuttingHistoryTable.tsx`, `SODetailModal.tsx`, `RollUsageHistoryModal.tsx`: ปรับป้าย "ขาว" ให้ใช้สไตล์ขาวมุกตัดขอบเทาเข้ม
4. **การตรวจสอบและยืนยันผล (Verification):**
   - ตรวจสอบการคอมไพล์ TypeScript และ Linter
   - ทดสอบการกด Numpad ทั้ง 5 ช่องในหน้าตัดฟอยล์ และตรวจดูความกระชับของแดชบอร์ดแซนวิช
